## 🖼️ What Is Block Poster?

A block poster is a large image printed across multiple sheets of paper.

The original image is divided into a grid of smaller sections, with each section printed on a separate sheet.

When all sheets are arranged in the correct order and attached together, they recreate the original image at a much larger physical size.

This technique is also known as:

- Tiled printing
- Poster tiling
- Multi-page poster printing
- Large-format image printing
- Rasterbating

Block Poster automates this process.

Instead of manually cropping an image into dozens of pieces, users can generate a complete multi-page PDF in just a few steps.

### Example: A 3 × 3 Poster

An original image can be divided into nine individual pages:

```text
+----------+----------+----------+
|   1-1    |   1-2    |   1-3    |
+----------+----------+----------+
|   2-1    |   2-2    |   2-3    |
+----------+----------+----------+
|   3-1    |   3-2    |   3-3    |
+----------+----------+----------+
```

Each page contains a different portion of the original image.

After printing and assembling the nine sheets, the complete poster is restored.

## ⚙️ How It Works

Block Poster uses an image-tiling workflow to convert a single image into multiple printable PDF pages.

The general process consists of four main stages.

### Stage 1: Upload and Crop

The user selects an image from their device.

The image is loaded into the browser and displayed in the editing interface.

The crop tool allows the user to select the desired image area.

### Stage 2: Configure the Poster Layout

The user chooses:

- Paper size.
- Paper orientation.
- Number of pages horizontally.
- Number of pages vertically.
- Printing margins.
- Overlap distance.

The application calculates the corresponding poster layout and updates the preview.

### Stage 3: Generate the PDF

The original image is divided into smaller sections according to the configured grid.

Each section is positioned on its corresponding PDF page.

The application also adds page coordinates and assembly information.

### Stage 4: Print and Assemble

The generated PDF is downloaded.

Each page is printed separately at its original scale.

The user then trims the appropriate edges, aligns neighboring pages, and joins them using tape or adhesive.

## 📐 Paper Sizes and Layout Options

Block Poster supports three common paper formats.

| Paper Size | Width | Height |
|---|---:|---:|
| A4 | 210 mm | 297 mm |
| A3 | 297 mm | 420 mm |
| US Letter | 215.9 mm | 279.4 mm |

Both portrait and landscape orientations are available.

### Choosing the Right Paper Size

**A4**

Best for standard home and office printers in many countries.

**A3**

Useful for larger individual tiles and reducing the total number of pages required.

**US Letter**

Designed for printers using the standard US Letter paper format.

Always select the same paper size in Block Poster and your printer settings.

A4 and US Letter are not interchangeable.

### Grid Configuration

| 4 | 4 | 16 |
| 5 | 4 | 20 |
| 5 | 5 | 25 |

The total number of sheets is calculated as:


## 🖨️ Image Quality and DPI

DPI stands for Dots Per Inch.

It is an important measurement when preparing images for physical printing.

Block Poster provides a print-quality estimate based on the source image and the configured poster dimensions.

General recommendations:

| Effective DPI | Expected Quality | Recommended Usage |
|---|---|---|
| Below 90 | Low | Large images viewed from a distance |
| 90–149 | Moderate | General wall displays |
| 150–299 | Good | Most poster printing projects |
| 300 | High | Detailed prints and close viewing |

### Recommended Image Resolution

For better results:

- Start with a high-resolution original image.
- Avoid excessive cropping.
- Consider the final physical poster dimensions.
- Check the estimated DPI before exporting.

A larger poster requires more source pixels to maintain the same level of detail.

**Recommended target: 150 DPI or higher.**

The maximum PDF export setting does not automatically guarantee that the original image contains enough detail for 300 DPI printing.

## 📌 Printing and Assembly Guide

Generating a PDF is only part of the process.

Correct printing and assembly are essential for achieving a clean final result.

### 1. Match the Paper Size

Use the same paper format selected during poster creation.

For example, if you configured A4, load A4 paper into your printer.

### 2. Print at Actual Size

This is the most important printing setting.

Choose:

```text
Scale: Actual Size
      or
Scale: 100%
```

Avoid:

```text
Fit to Page
Shrink to Fit
Automatic Scaling
```

Automatic scaling can change the physical dimensions of individual pages and prevent accurate alignment.

### 3. Print One Test Page

Before printing the entire poster:

- Print the first poster tile.
- Check the physical dimensions.
- Verify image quality.
- Check the printer margins.
- Confirm that the selected paper orientation is correct.

### 4. Trim the Edges

Trim the appropriate overlapping edges to create clean joining surfaces.

Avoid removing the edges needed for alignment.

### 5. Arrange the Pages

Use the printed coordinate labels.

Arrange pages from left to right and from top to bottom.

### 6. Align and Attach

Match the image details across neighboring pages.

Use the overlap area to help align the sheets.

Attach the pages using masking tape or suitable adhesive.

For best results, assemble the poster on a flat surface and secure the joints from the back.

### 7. Final Inspection

Check that:

- All pages are in the correct order.
- Image details align properly.
- No sections are missing.
- The overall poster is flat.
- The joints are securely attached.

### Which paper sizes are supported?

The available formats are A4, A3, and US Letter.

### Can I create very large posters?

Yes.

You can increase the number of rows and columns to create larger posters.

The practical maximum size depends on the available grid settings, device memory, image resolution, and printing requirements.

### How much overlap should I use?

A starting value of 5–10 mm is recommended for most home printing projects.

The most common cause is incorrect print scaling.

Make sure you select Actual Size or 100% and disable Fit to Page.

The source image may not contain enough pixels for the final poster dimensions.

Use a higher-resolution image and check the estimated effective DPI before exporting.

### Can I use a regular home printer?

Yes.

Any printer that supports the selected paper format can be used to print the individual PDF pages.

### Can I print the PDF later?

Yes.

Download the generated PDF and store it on your device.
